# KHCI 2027 서론 초안

작성일: 2026-11-10

상태: 사용자의 요청에 따라 실험을 완료한 상황을 가정한 논문 문체로 작성했다. 실제 사용자 실험의 수행·결과를 확인했다는 뜻이 아니다. 참가자 수, 통계 결과, 성능의 우열은 추가하지 않았다. 제출 전 실제 수행한 방법과 맞춰 수정한다.

## 1. 서론

이동 로봇의 조종 인터페이스는 사용자의 이동 의도를 로봇의 동작으로 전달하고, 사용자가 동작 결과를 확인하며 다음 입력을 결정하도록 연결한다. 장애물 사이를 통과하는 주행 과제에서는 주변 공간을 파악하면서 이동 방향과 회전을 조절해야 하므로, 조종 방식에 따른 수행 효율과 사용자 부담을 함께 살펴볼 필요가 있다. Baker 등은 몰입형 환경에서 직접 조종과 경유점 지정 방식을 비교하고, 과제 수행과 작업부하 및 사용성을 평가하였다[1]. 이러한 접근은 이동 로봇 인터페이스의 평가에서 사용자의 조작 과정과 제어 역할을 함께 고려할 필요성을 보여준다.

혼합현실(Mixed Reality, MR)은 실제 환경을 관찰하면서 가상 객체와 손 동작을 이용해 로봇에 명령을 전달할 수 있는 상호작용 환경을 제공한다. Esaki와 Sekiyama는 작업 환경을 MR 공간에 표현하고, 손 동작을 통한 객체 조작과 이동 경로 수정을 로봇 동작에 연결하는 시스템을 제시하였다[2]. 또한 Taki 등은 실제 바닥 위에 손 동작으로 이동 경로를 그리는 MRReP를 제안하고, 기존 2차원 인터페이스와 경로 지정 정확도 및 주관적 사용 경험을 비교하였다[3]. 이들 연구를 바탕으로, 본 연구는 MR을 활용한 직접 조종과 경로 지정이 실제 장애물 통과 과제에서 나타내는 수행 특성에 주목하였다.

직접 조종과 경로 지정은 사용자가 이동에 관여하는 시점과 방식에서 차이가 있다. 직접 조종에서는 이동 중 전후 이동과 회전 입력을 지속적으로 조절한다. 경로 지정에서는 이동 전에 경로를 작성하고 실행을 지시하며, 필요에 따라 경로를 수정하거나 이동에 개입한다. 이에 본 연구에서는 경로 작성, 수정, 실행 및 재조정을 포함한 전체 과제 수행 시간을 비교 기준으로 설정하였다. 이를 통해 이동을 실행하는 시간과 사용자가 계획하고 조정하는 데 드는 시간을 함께 평가하고자 하였다.

본 연구는 사족보행 로봇 PuppyPi를 대상으로 스마트폰 터치 조이스틱, MR 환경의 가상 손잡이 기반 직접 조종, 라이다 지도 기반 경로 스케치의 세 가지 조종 방식을 구성하였다. 스마트폰 방식과 MR 가상 손잡이 방식은 사용자의 연속적인 입력으로 로봇을 조종하며, 경로 스케치 방식은 MR 공간에 제시된 라이다 지도 위에 사용자가 손으로 그린 경로를 로봇이 따라 이동하도록 하였다. 사용자 실험에서는 실제 로봇을 관찰하면서 동일한 장애물 코스를 통과하여 목표 구역에 로봇을 정지시키는 과제를 수행하도록 하였다. 전체 과제 수행 시간과 목표 도달 성공률을 주요 지표로 설정하고, 앱·로봇 로그를 통한 정지·재개 및 조작 개입 분석과 설문을 통한 작업부하·사용성 평가를 함께 실시하였다.

본 연구의 목적은 세 조종 방식의 목표 도달 수행을 비교하고, 계획·수정·개입 과정이 전체 수행과 사용자 부담에 어떻게 연결되는지 살펴보는 데 있다. 세 조건은 입력 장치, 제공 정보 및 자동화 수준을 포함한 시스템 구성으로 비교하였으며, 결과도 각 구성에서 나타나는 사용자 수행 특성으로 해석하였다. 이를 바탕으로 동일한 장애물 통과 과제에서 연속적인 직접 조종과 경로 지정의 특성을 비교하고, 사족보행 로봇 조종 인터페이스의 설계 시사점을 논의하였다.
