# ROS 2 LiDAR 정지 판단 — 최신 전달 문서

최신 요구사항은 [로봇 CLI AI 작업 지시서](ROS2_PATH_RELIABILITY_HANDOFF.md)입니다. 로봇의 원시 LiDAR 장애물 정지·clear-hold를 제거하고, 장애물 필터·경로 취소·우회는 MR에서 처리합니다. 로봇에 새로운 근접 정지·관측 횟수·빈 공간 해제 조건을 추가하는 이전 제안은 적용 대상이 아닙니다.

변경할 파일, 유지할 비상정지·소유권·통신 timeout, 실행 ID와 필수 검증은 최신 지시서를 따르세요. 로봇 정지 보호 전체를 삭제하는 작업이 아닙니다.
