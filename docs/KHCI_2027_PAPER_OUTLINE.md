# KHCI 2027 논문 목차안: 입력·제어 방식의 설계 및 기술적 비교

작성일: 2026-11-11

## 1. 현재 집필 방향

참가자를 모집한 사용자 수행·설문 비교를 논문의 중심에 두지 않는다. 구현한 스마트폰 터치, MR 가상 손잡이, MR 지도 경로 스케치의 명령 표현·입력 유지 요구·수정 절차·실행 조건·오류 복구를 공통 기준으로 분석하고, 필요한 주장을 반복 가능한 동작 시험과 앱·로봇 로그로 뒷받침한다.

이 문서는 목차와 작성 범위의 제안이다. 시험을 이미 수행했다거나 수치 결과가 확인되었다는 뜻이 아니다. 앞서 작성한 요약문·서론·연구 설계 초안은 사용자 수행 비교를 중심에 둔 이전 방향이므로, 본 목차를 채택하면 목적·방법·기여를 함께 수정해야 한다.

작업 제목 후보:

> 사족보행 로봇 조종을 위한 터치·혼합현실 직접 조종·경로 스케치 방식의 설계 및 기술적 비교

핵심 질문:

> 세 입력·제어 방식은 명령의 표현 수준, 지속 입력 요구, 이동 수정 절차와 오류 복구에서 어떤 차이를 가지는가?

입력 장치, 지도 정보, 경로 실행의 자동화가 함께 달라지므로 시스템 구성별 특성을 분석한다. 특정 손 동작만의 독립적인 효과를 입증한 비교로 기술하지 않는다.

## 2. 추천 목차

요약문  
주제어

### 1. 서론

- 로봇 이동 의도를 전달하는 여러 입력·제어 방식의 필요성.
- 연속적인 이동 입력과 경로 지정의 역할 차이.
- 본 논문의 대상, 비교 목적 및 기여.
- 참가자 수행·선호를 검증하는 연구와 구별되는 본 논문의 분석 범위.

### 2. 관련 연구

#### 2.1 이동 로봇의 직접 조종 인터페이스

터치·조이스틱 등 연속 입력으로 이동·회전을 제어하는 방식. 기존 방식의 장점과 제약을 관련 문헌의 근거에 맞춰 정리한다.

#### 2.2 MR 기반 로봇 상호작용과 경로 지정

가상 객체 조작, 손 추적, 지도·공간상의 경로 스케치를 다룬다. MRReP 등과의 공통점 및 이번 구현·비교에서 다루는 범위를 명확히 한다. 경로 스케치 자체가 최초라는 주장은 하지 않는다.

문헌 검토의 마지막 문단에서 세 방식의 차이를 분석할 관점을 연결한다.

### 3. 시스템 설계 및 구현

#### 3.1 전체 시스템 구성과 공통 제어 구조

PuppyPi, 스마트폰, MR 장치, 지도·위치 데이터와 제어 메시지의 흐름을 설명한다. 세 방식이 공유하는 로봇·통신·정지 동작과 조건별로 달라지는 기능을 구분한다. 하드웨어와 실제 적용 버전·설정을 명시한다.

#### 3.2 스마트폰 터치 조종

터치 조이스틱의 입력 축, 이동·회전 명령으로의 변환, 입력 유지와 해제, 이동 시작·수정·중단 절차를 기술한다.

#### 3.3 MR 가상 손잡이 조종

손 추적과 잡기, 손잡이 변위와 제어 명령의 연결, 해제·추적 상실·재획득 시 동작을 기술한다. 구체적인 구현에서 확인한 입력 축과 매핑을 사용한다.

#### 3.4 라이다 지도 기반 경로 스케치

지도·로봇 위치의 표시, 손으로 선 그리기, 경로 보정·검증, 실행 요청, 진행 피드백을 설명한다. 사용자가 그린 선, 보정 경로, 실제 전송·실행 경로를 구별한다.

최신 [지도 경로 편집 기능 문서](MR_MAP_PATH_EDITOR.md)에는 자동 우회도 포함되어 있다. 논문 대상 버전에 이를 포함하면, 원래 경로와 자동 수정 경로를 구분하고 우회 조건·자동화 범위도 본 절과 4.3에 명시한다. 이전 연구 초안의 '자동 우회 없음'을 현재 구현의 설명으로 재사용하지 않는다. 문서상의 구현 설명은 실기 검증 완료를 뜻하지 않는다.

#### 3.5 중단·수동 전환 및 예외 처리

정지·취소, 경로 실행에서 직접 조종으로의 전환, 통신·추적·지도 정보 이상 시 처리 절차를 설명한다. 세 방식이 공유하는 규칙과 특정 방식에만 필요한 규칙을 상태 전이도로 정리한다.

### 4. 입력·제어 방식 비교 및 동작 검증

#### 4.1 비교 기준과 시험 환경

비교 축은 명령 단위, 지속 입력 요구, 필수 정보·장치, 수정 절차, 실행 피드백, 오류·복구 조건으로 설정한다.

시험에는 실제 로봇을 관찰하는 동일한 환경과 지정된 장애물 배치를 사용한다. 로봇·지도·통신·속도 설정, 시험 절차, 조작자, 반복 횟수, 성공·실패 판정, 로그 시각과 측정 시작·끝을 명시한다. 반복 횟수와 수치 임계값은 아직 확정된 값처럼 쓰지 않는다.

#### 4.2 입력 구조와 조작 절차 비교

세 방식의 특성을 동일한 표로 정리하고 이동 시작, 방향 변경, 정지, 경로 변경에 요구되는 동작·상태 전이를 비교한다. 연속 입력의 터치·잡기 횟수와 경로 방식의 waypoint 수를 동등한 작업량으로 단순 합산하지 않는다.

'실행 단계에서 지속적인 사용자 이동 입력이 필요한가'처럼 구조에서 확인할 수 있는 특성과 시험 측정값을 구분한다.

#### 4.3 시나리오별 동작 검증과 기술 측정 결과

공통 사례는 직선 이동, 방향 전환, 장애물 통과, 이동 중 정지·수정으로 구성한다. 방식별 예외는 손 추적 상실, 경로 거부, 지도·센서 정보 만료, 취소·수동 전환을 포함할 수 있다. 자동 우회를 논문에 포함하면 우회 시도·실패·취소를 별도로 기록한다.

측정 후보:

- 앱 내부의 입력 처리·명령 생성 시간.
- 명령 전송부터 수락 ACK까지의 시간.
- 취소 요청부터 최신 실행 상태의 비활성 반영까지의 시간.
- 정의한 시험별 동작 성공·실패 건수와 원인.
- 경로 작성·보정·검증·계획 시간 및 경로 수정 사건: 경로 방식 내부의 지표.
- 연구자가 정해진 절차로 수행한 시나리오의 완료 시간: 해당 조작자·설정의 사례 결과.

송신→ACK를 물리적 이동 반응 시간으로, 취소→비활성 상태 반영을 실측 물리 정지 시간으로 부르지 않는다. 시계 동기화가 검증되지 않은 장치 시각을 직접 빼지 않는다. 외부 계측 없이 얻은 pose는 추정 좌표계의 결과로 보고하며, 센서 장애물 정지 사건을 실제 접촉 횟수로 바꾸어 해석하지 않는다.

### 5. 논의

#### 5.1 방식별 장단점과 적용 조건

4장에서 확인한 사실을 근거로 이동 중 즉시 조정, 사전 경로 표현, 필요한 장치·정보, 추적·지도 의존성, 중단·복구 절차의 차이를 설명한다.

예: 경로 방식의 실행 단계에서는 지속적인 이동 입력이 필요 없지만, 지도·위치·경로 검증이 실행의 선행 조건이다. 이 사실만으로 사용자가 덜 피곤하거나 더 쉽게 배운다고 결론내리지 않는다.

#### 5.2 연구의 한계와 향후 과제

사용자 모집 실험을 하지 않았다면 학습 용이성·직관성·피로·작업부하·선호의 검증은 범위에 포함되지 않음을 명시한다. 단일 조작자 시험과 반복 시행은 다수 사용자의 수행 근거로 일반화하지 않는다. 로봇 위치추정·실제 보행·환경 범위·장치 차이도 결과 해석에 연결한다.

### 6. 결론

무엇을 구현했고 어떤 기준으로 비교했는지, 시험에서 확인된 핵심 차이가 무엇인지 요약한다. 실제 결과에 맞춰 설계 시사점을 제시한다.

## 3. 장별 역할과 분량 제안

총 6쪽을 작업 목표로 잡았을 때의 배분이다. 학회의 규정 자체를 제시하는 표는 아니다. 실제 템플릿에서 그림·표·참고문헌을 배치하며 조정한다.

| 구성 | 권장 분량 | 핵심 자료 |
| --- | --- | --- |
| 요약문·주제어·1장 | 0.8쪽 | 연구 목적·기여 |
| 2장 | 0.5쪽 | 직접 조종·MR·경로 지정 문헌 |
| 3장 | 2.0쪽 | 시스템 구성도, 세 인터페이스 화면, 상태 전이 |
| 4장 | 1.6쪽 | 공통 특성 표, 시험 배치, 로그·측정 결과 |
| 5장 | 0.4쪽 | 근거에 연결한 장단점과 한계 |
| 6장·참고문헌 | 0.7쪽 | 핵심 결론·인용 자료 |

3장은 '어떻게 만들었는가', 4장은 '무엇이 다르고 어떤 동작을 확인했는가', 5장은 '그 차이가 어떤 조건에서 의미 있는가'를 담당한다. 구현 설명과 장단점 의견이 반복되지 않도록 한다.

분량이 줄어들면 3.5를 3.1·3.4에 통합하고 5장을 '논의 및 한계'로 한 절에 묶는다.

## 4. 준비할 그림과 표

1. 전체 시스템 구성도: 입력 장치→명령·경로 처리→로봇 실행→지도·상태 피드백.
2. 세 조종 화면을 나란히 제시한 그림.
3. 이동 시작·실행·중단·수동 전환의 상태 전이 그림.
4. 입력·제어 특성 비교 표: 세 방식에 같은 행을 적용.
5. 시험 시나리오·판정·측정 기준 표 및 결과 표/그래프.

그림과 표는 최종 분량에 맞춰 통합한다. 실제 결과가 없으면 결과 그래프에 가정 수치를 넣지 않는다.

## 5. 확인한 같은 학회 논문의 구성

아래는 2026-11-11에 DBpia 상세 페이지와 원문 뷰어에서 직접 확인한 내용이다. DBpia의 AI 요약을 본문 근거로 사용하지 않았다. 관찰한 사례를 정리한 것으로, 해당 구성이 필수 양식이거나 채택을 보장한다는 뜻은 아니다.

### A. 사용자가 지정한 논문

참고점: 기존 구조 분석→설계 제안→특성 비교의 전개. 우리 목차에서는 3장과 4장에 구체적인 이름을 붙여 구현과 비교·검증을 구분한다.
