# KHCI 2027 서론 초안: 입력·제어 방식의 설계 및 기술적 비교

작성일: 2026-11-11

상태: 최신 [논문 목차안](KHCI_2027_PAPER_OUTLINE.md)에 맞춘 집필 초안이다. 사용자 모집·설문 평가를 중심에 둔 이전 서론과 별도 보관한다. 구현은 사용자가 설명한 시스템을 기준으로 서술했으며, 동작 검증의 완료나 결과 수치를 확인했다는 뜻은 아니다. 실제 적용·시험한 방법과 버전에 맞춰 제출 전에 수정한다.

## 1. 서론

이동 로봇을 원하는 위치로 이동시키기 위해서는 사용자의 의도를 로봇이 실행할 수 있는 명령으로 변환하는 조종 인터페이스가 필요하다. 사용자가 이동 방향과 회전을 지속적으로 입력하는 직접 조종과, 목표 지점이나 경로를 지정하여 이동을 실행하는 방식은 명령의 표현 수준과 사용자·로봇 간 제어 역할에서 차이가 있다. Baker 등은 몰입형 환경에서 직접 조종과 경유점 지정 방식을 비교하며 이동 로봇의 제어 방식을 달리 구성하고 평가한 사례를 제시하였다[1]. 이러한 차이를 이해하는 것은 로봇 조종 인터페이스의 구성과 적용 조건을 결정하는 데 필요하다.

혼합현실(Mixed Reality, MR)을 활용하면 실제 환경을 관찰하면서 가상 객체와 손 동작을 통해 로봇에 이동 의도를 전달할 수 있다. 특히 이동 의도를 공간상의 경로로 표현하는 방식은 연속적인 이동·회전 입력과 다른 명령 구조를 제공한다. Taki 등은 실제 바닥 위에 손 동작으로 이동 경로를 그리는 MRReP를 제안하고, 작성된 경로를 이동 로봇의 내비게이션에 연결하였다[2]. 이와 같이 MR 기반 조종은 손 동작을 직접적인 이동 입력으로 활용하거나, 로봇이 실행할 경로를 지정하는 형태로 구성할 수 있다.

각 방식을 실제 시스템에 적용할 때에는 명령의 표현뿐 아니라 입력 유지 요구와 실행 조건을 함께 고려해야 한다. 직접 조종은 이동 중 입력을 지속적으로 조절하는 구조이며, 경로 지정은 경로 작성·검토·실행과 필요에 따른 수정 절차를 갖는다. 또한 MR 손 입력은 추적 상태에, 지도 기반 경로 지정은 지도와 로봇 위치 정보에 의존한다. 따라서 각 방식의 특성을 설명하기 위해서는 필요한 장치와 정보, 이동 수정 절차, 실행 상태의 피드백 및 입력·통신 이상 시 복구 동작을 공통 기준으로 분석할 필요가 있다.

이에 본 연구는 사족보행 로봇 PuppyPi를 대상으로 스마트폰 터치 조종, MR 가상 손잡이 조종, 라이다 지도 기반 경로 스케치의 세 가지 입력·제어 방식을 설계하고 구현하였다. 스마트폰 방식은 터치 조이스틱을 통해 이동·회전 명령을 입력하며, MR 가상 손잡이 방식은 손으로 가상 손잡이를 잡고 움직이는 동작을 제어 명령에 연결한다. 경로 스케치 방식은 MR 공간에 제시된 라이다 지도 위에 손으로 그린 선을 이동 경로로 변환하고, 경로 보정과 검증을 거쳐 로봇의 이동을 실행하도록 구성하였다. 세 방식은 동일한 로봇 플랫폼과 실제 로봇을 관찰하는 조종 환경을 대상으로 한다.

본 연구에서는 세 방식의 명령 단위, 지속 입력 요구, 필수 정보, 수정 절차 및 오류 복구 조건을 비교한다. 또한 이동 시작, 방향 전환, 장애물 통과, 중단과 경로 수정 시나리오를 구성하고, 앱·로봇 로그를 활용하여 명령 처리와 실행 상태 전이의 동작을 검증한다. 이를 통해 입력 장치와 제어 역할이 다른 조종 방식의 구조적 특성과 운용상의 제약을 정리하고, 사족보행 로봇 조종 인터페이스의 설계 및 선택을 위한 시사점을 제시한다.

- [1]은 직접 조종과 경유점 지정의 비교 사례로, [2]는 MR 경로 스케치와 이동 로봇 내비게이션의 연결 사례로 인용했다. 두 문헌 모두 사용자 실험도 포함하므로 참가자 없는 논문의 사례로 소개하지 않는다.
